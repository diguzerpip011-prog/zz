# Obiettivo Unghie di Francesca Bove

Sito web statico del centro estetico Obiettivo Unghie, Viale di Villa Pamphili 77, Roma.

Apri `index.html` in un browser per vederlo. Non servono build o dipendenze.
Per pubblicarlo basta caricare `index.html` e `style.css` su qualsiasi hosting statico, per esempio GitHub Pages.
